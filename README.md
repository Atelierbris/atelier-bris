# Atelier Bris Site

Sito vetrina statico per Atelier Bris.

## Struttura

- `index.html`: home
- `apps/index.html`: pagina Apps
- `experiences/index.html`: pagina Experiences
- `contact/index.html`: pagina Contattaci
- `assets/`: loghi e immagini
- `styles.css`: layout responsive e animazioni
- `script.js`: menu mobile e reveal on scroll

## Preview locale

Aprire `index.html` nel browser oppure avviare un server statico dalla cartella:

```bash
python3 -m http.server 4173
```

## Deploy

La cartella puo essere caricata come sito statico. Per Netlify e sufficiente trascinare questa cartella nella dashboard oppure collegarla a un repository.
